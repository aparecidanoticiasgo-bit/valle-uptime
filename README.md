# valle-uptime

Alerta de queda do navio Valle. A cada 10 minutos o GitHub Actions testa os sites públicos e a saúde da API (`/api/v1/health` com `db:ok`). Se algo cair, o job falha e o GitHub avisa por e-mail.

Repositório público de propósito: Actions em repo público não gasta minutos. Aqui só existem endereços que já são públicos, sem senha nem dado.
